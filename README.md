# VPS: VK TURN одной командой

Лёгкий сервер для **FreeTurn на Android** и **VK TURN Proxy (anton48) на iPhone**. Оба приложения используют один сервер FreeTurn → обычный kernel WireGuard → интернет. Отдельный второй сервер для iPhone не требуется.

По умолчанию: один небольшой транспортный процесс, два профиля телефонов, WireGuard в ядре и Fail2ban для SSH. Без Docker, сборки Go на VPS, панели, DNS-туннеля и постоянно открытого звонка VK. Уже установленный 3X-UI KIT сохраняется.

## Установка

Ubuntu 22.04/24.04 или Debian 12/13, systemd, amd64/arm64, root. Рекомендуется от **512 МБ RAM**; для KIT — от 1 ГБ. Нужна ваша ссылка VK-звонка. На чистой VPS с доступным `curl` выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NimmWee/Vps/main/install.sh)
```

Скрипт попросит ссылку звонка, скрывая ввод. Для подключения не требуется постоянно держать звонок открытым. При CAPTCHA её решают на телефоне в клиентском приложении.

Если вы хотите одновременно установить и **3X-UI KIT**, используйте одну команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NimmWee/Vps/main/install.sh) --with-kit
```

Это более тяжёлый вариант: upstream KIT устанавливает собственную панель и выбранные протоколы, задаёт свои вопросы. Если KIT уже найден, его установщик и CLI не запускаются. Лёгкая конфигурация VK сама по себе KIT не требует. Поведение установки нового KIT передано его проверяемому upstream-скрипту; тестирование этого проекта проводилось рядом с уже установленным KIT.

Скрипт проверяет ОС и архитектуру, скачивает закреплённый пакет v1.0.0 и проверяет SHA-256 **до запуска Python**. Транспорт FreeTurn 4.1.2-vps1 собран заранее для двух архитектур. Подробности — `NOTICE.md`, `artifacts/manifest.json`, `third_party/` и `scripts/build-freeturn.sh`.

## Порты и защита

| Назначение | По умолчанию |
|---|---|
| FreeTurn, доступ от VK relay | UDP 56001 |
| WireGuard backend | UDP 51830, вход извне блокируется |
| SSH Fail2ban | Реальные SSH-порты из `sshd -T`, обычно TCP 22 |
| VPN-подсеть | 10.77.43.0/24 |
| Интерфейс | vkvpn0 |

В панели провайдера разрешите входящий **UDP 56001**. Правила на самой VPS добавляет установщик. Другие правила firewall и маршрут по умолчанию не очищаются. При конфликте порта выбирайте другие порты в аргументах; при конфликте подсети — другую свободную RFC1918 /24.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NimmWee/Vps/main/install.sh) --port 56002 --backend-port 51831 --subnet 10.77.44.0/24
```

Fail2ban: **3 ошибки за 10 минут → фиксированный бан на 30 дней**, хранение базы 35 дней, без постоянного исключения для внешнего IP администратора. Имеющиеся другие jails сохраняются. SSH-пароли, ключи и способы входа установщик не меняет. Держите доступ к консоли провайдера на случай своего бана.

Служба работает отдельным непривилегированным пользователем. MemoryHigh 64 МБ, MemoryMax 96 МБ, GOMEMLIMIT 48 MiB, один поток Go, CPUQuota 50%. Это ограничения транспортного процесса, а не всей ОС или Fail2ban. Ограничение CPU может снижать максимальную скорость.

VPN-клиентам закрыт доступ к самой VPS и частным/служебным IPv4-адресам. IPv6-выход не предоставляется; пересылка IPv6 блокируется. Утечки и поведение конкретного телефона нужно проверить на самом устройстве.

## Конфиги телефонов

```bash
vps-vk profiles --show
```

Ссылки также лежат в `/var/lib/vps-vk/main/profiles/iphone-import.txt` и `android-import.txt`, root-only. Они содержат ключи доступа. Не помещайте их в GitHub, публичные подписки или чужие QR-сервисы.

**iPhone:** [VK TURN Proxy от anton48](https://github.com/anton48/vk-turn-proxy-ios). Settings → Import from connection link; в некоторых сборках пункт находится в Backup & Restore. Вставьте всю строку `vkturnproxy://…`. Профиль **VK VPS iPhone**, **SRTP-WRAP-S**, **rtpopus3**, 6 соединений, Use UDP выключен. Разрешите VPN-конфигурацию iOS.

**Android:** [официальные релизы FreeTurn](https://github.com/hackdiaz-dev/turn-proxy-android/releases). «Соединение» → «+» → импорт ссылки/QR, вставьте всю строку `freeturn://…`. Режим Relay/VK, TCP к TURN; встроенный WireGuard/VPN включите, если установленная сборка просит это отдельно. Конфигурация WireGuard уже включена, нестандартные параметры AmneziaWG не нужны. Для начала соединения используйте DNS оператора/автоматический DNS.

QR опциональны: `--qr` при установке добавляет небольшой пакет qrencode, затем `vps-vk profiles --qr` создаёт PNG рядом с текстовыми профилями.

После подключения проверьте сайты, внешний IPv4, работу на мобильной сети во время ограничений, блокировку экрана и переключение Wi-Fi/LTE. Установка на VPS не может подтвердить работу на вашем операторе или решить CAPTCHA за приложение.

## Переезд, когда IP заблокируют

**Сделайте копию заранее и скачайте её с VPS.** Копия на том же сервере не поможет, когда доступ к нему пропадёт.

```bash
vps-vk backup /root/vpn.vkbackup
```

Будет запрошена отдельная длинная парольная фраза. Копия шифруется AES-256-CBC/PBKDF2 и защищается отдельным HMAC-SHA256; целостность проверяется до расшифровки. Внутри только проверяемый JSON с VPN-ключами, ссылкой VK и параметрами — без исполняемых файлов, cron, системных каталогов или KIT-базы.

На новой чистой VPS загрузите `vpn.vkbackup` в `/root`, затем выполните одну команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NimmWee/Vps/main/install.sh) restore /root/vpn.vkbackup
```

Установщик сохранит VPN-ключи и ссылку VK, определит новый IPv4 и создаст новые ссылки для обоих телефонов. **Переимпортируйте их на телефонах:** старый профиль с буквальным IP сам не изменится. Если старый сервер был скомпрометирован, безопаснее чистая установка с новыми ключами вместо восстановления старых.

Можно явно задать адрес или доменное имя: `--endpoint vpn.example.org`. Работу доменного endpoint нужно проверить в фактических сборках мобильных клиентов; автоматический бесшовный переезд не обещается.

## Повторный запуск и управление

Повтор той же команды сохраняет ключи и ссылку VK; `--endpoint НОВЫЙ_IP` обновляет адрес. В уже управляемой установке существующие порты и подсеть сохраняются — это не команда смены сетевого плана.

```bash
vps-vk status
vps-vk profiles --endpoint 203.0.113.1  # замените пример реальным публичным IP
systemctl restart vps-vk-network vps-vk
journalctl -u vps-vk -n 30 --no-pager
```

Профили не публикуются через HTTP. Команда `profiles --show` печатает их только по явному запросу. Не публикуйте вывод этой команды или полные клиентские журналы.

Для прежней установки из этого проекта с units `kit-freeturn`, файлами `/etc/kit-freeturn` и двумя телефонными профилями предусмотрен явный перенос:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NimmWee/Vps/main/install.sh) --adopt-legacy --vk-link-file /root/vk-call-url.txt
```

Перед остановкой прежних служб проверяются пары ключей. При неудаче прежняя служба запускается обратно. После успеха прежние units отключаются; исходные файлы сохраняются для отката. Произвольные чужие установки автоматически не импортируются.

Удалить только этот транспорт: `vps-vk uninstall`. Его интерфейс и помеченные правила удаляются, ключи и копии остаются. SSH Fail2ban и KIT сохраняются. Глобальный forwarding не выключается, поскольку его могут использовать другие службы.

## Проверки и ограничения

Разработка: `python3 -m unittest discover -s tests -v`, `bash -n install.sh scripts/build-freeturn.sh`, `python3 scripts/verify-package.py`. CI проверяет исходники, шифрованные копии, профили и совпадение распространяемого пакета с исходниками.

Транспорт собран для amd64 и arm64; фактическое VPS-испытание выполняется на Ubuntu 24.04 amd64. Нет физического E2E-теста обоих телефонов, испытания всех операторов или гарантии доступности VK/отсутствия CAPTCHA. Новая установка KIT и остальные заявленные ОС требуют отдельных испытаний.

Источники: [FreeTurn server](https://github.com/hackdiaz-dev/free-turn-proxy), [Android client](https://github.com/hackdiaz-dev/turn-proxy-android), [iPhone setup](https://github.com/anton48/vk-turn-proxy-ios/blob/main/docs/setup.md), [3X-UI KIT](https://github.com/itsnotkubrick/3X-UI_KIT).
